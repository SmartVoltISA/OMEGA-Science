# OMEGA-Science

Открытая научно-инженерная лаборатория применения Ω-инструментов к фундаментальным и прикладным наукам.

## Цель

Проверять один и тот же реляционный инструмент на разных научных областях — не подгоняя науку под Ω, а сравнивая результаты с существующими моделями и фиксируя границы применимости.

## Основной цикл

`наука → модель → отношения → Ω-инструмент → эксперимент → сравнение → результат`

## Направления

- физика;
- химия;
- биология;
- математика;
- информатика;
- экономика;
- далее: нейронаука, экология, медицина, материаловедение и инженерные системы.

## Что исследуем

- отношения;
- память;
- жёсткость;
- связность;
- пространство выбора;
- концентрацию;
- потоки;
- обратную связь;
- устойчивость и переходы между режимами.

## Статусы

Каждый результат разделяется на:

`OBSERVED → DERIVED → MODEL → HYPOTHESIS`

Для прикладной ценности дополнительно:

`REDUNDANT / USEFUL / SUPERIOR / CONFLICT`

`PASS / FAIL / INVALID` сохраняются для самих экспериментов.

## Правило

Ω не заменяет существующую науку по умолчанию. Если известная модель объясняет результат лучше — это фиксируется. Если Ω не даёт дополнительной информации — результат также фиксируется. Если появляется дополнительный измеримый эффект — он проходит независимую проверку.
