# MASS-002 — Динамическое возникновение массы

**Status:** DERIVED / MODEL-VALIDATED
**Scope:** фундаментальная физика
**Question:** может ли масса возникнуть без явно заданного mass-term?

## Критерий

Величину разрешаем называть mass-like только если она:
1. относится к устойчивому состоянию;
2. входит в дисперсию `E² = c_eff² p² + m_eff² c_eff⁴`;
3. инвариантна относительно допустимой релятивистской симметрии модели;
4. остаётся конечной при удалении конечного-размера артефакта;
5. не была введена как исходный параметр массы.

## Результат

Простая графовая модель без взаимодействующего механизма дала gap, исчезающий как `N^-2`. Это FAIL: конечный-size gap не является массой.

Более сильная проверка использует известный контролируемый пример динамического образования масштаба — безмассовую Gross–Neveu-модель в большом-N приближении. В исходной лагранжиановой постановке отсутствует явный fermion mass term. Самосогласованное уравнение для динамического масштаба при cutoff `Λ` имеет вид

`1/g = asinh(Λ/m_dyn)/π`

откуда

`m_dyn = Λ / sinh(π/g)`.

Для слабой связи:

`m_dyn ≈ 2Λ exp(-π/g)`.

Следовательно, ненулевой масштаб появляется из безмассовой исходной теории через динамику взаимодействия и dimensional transmutation, а не из заранее заданной массы.

## Численная контрольная проверка

При `Λ = 1`:

| g | m_dyn |
|---:|---:|
| 0.5 | 0.0037349 |
| 0.6 | 0.0106434 |
| 0.7 | 0.0224893 |
| 0.8 | 0.0394211 |
| 0.9 | 0.0610183 |
| 1.0 | 0.0865895 |

Подстановка каждого значения обратно в gap equation даёт остаток численно равный нулю в машинной точности.

После динамического образования масштаба возбуждение имеет релятивистскую форму

`E(p)² = p² + m_dyn²`

в естественных единицах. Поэтому `m_dyn` удовлетворяет operational критериям массы внутри этой модели.

## Что это доказало

**PASS:** масса может быть динамически сгенерирована из взаимодействующей безмассовой модели; mass scale не обязан быть фундаментальным параметром исходного уравнения.

Это сильнее предыдущего графового эксперимента: gap не является конечным-размерным артефактом, а связан с самосогласованным динамическим масштабом.

## Что НЕ доказано

Это не доказательство происхождения массы нашей Вселенной.

Модель уже предполагает:
- релятивистскую кинематическую структуру;
- конкретную симметрию;
- взаимодействие определённого типа;
- cutoff/ренормализационную схему.

Следовательно, мы объяснили **механизм возникновения массы внутри заданной структуры**, но не происхождение самой структуры и не наблюдаемые значения масс Стандартной модели.

## Сильнейшая найденная опора

Ключевой механизм — **dimensional transmutation / dynamical mass generation**. Он показывает, что безмассовые исходные степени свободы могут получить ненулевой физический масштаб из взаимодействия.

Близкий физический контроль — QCD: наблюдаемая масса адронов существенно связана с динамикой сильного взаимодействия, а не с простой суммой текущих масс кварков.

## Граница

Следующий вопрос:

> Можно ли получить одновременно пространство-время/релятивистскую кинематику, устойчивый mass scale и наблюдаемую дисперсию из ещё более первичной relational/dynamical системы без постулирования Пуанкаре-симметрии?

Это остаётся `UNKNOWN`.

## Контроль источников

- Gross–Neveu model / dynamical mass generation — контролируемый теоретический пример.
- Symmetric Mass Generation literature — независимый класс механизмов образования gap без обычного Higgs breaking.
- QCD / lattice-QCD literature — контроль происхождения массы составных адронов.

**Вердикт:** `PASS` для утверждения «масса может возникать динамически без явного mass-term»; `UNKNOWN` для утверждения «мы вывели фундаментальную массу Вселенной».
